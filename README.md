# 🏦 Banking & Financial Assistant

An AI-powered Banking & Financial Assistant built with **ASP.NET Core MVC** and **Google Gemini AI**.

The application provides an interactive chatbot that helps users with banking and financial-related questions through a simple and modern chat interface.

---

## 🚀 Features

- 🤖 AI-powered chatbot using Google Gemini
- 💬 Real-time conversational interface
- 🏦 Banking & financial assistance
- 📱 Responsive design
- 🌙 Dark mode support
- 🔐 Secure API key configuration
- 🛡️ ASP.NET Core Anti-Forgery protection
- 🧠 Conversation history support
- 🎨 Modern and user-friendly UI

---

## 🛠️ Technologies Used

- **ASP.NET Core MVC**

- **Google Gemini AI**
- **HTML5**

## 🤖 Google Gemini AI Integration

The application uses **Google Gemini AI** to generate responses to user questions.

The Gemini API key is stored securely in the application's configuration and is **not exposed in the frontend or GitHub repository**.

Example configuration:

```json
{
  "Gemini": {
    "ApiKey": "YOUR_API_KEY",
    "Model": "YOUR_GEMINI_MODEL"
  }
}
